# Printer driver release assets

Release-сборка может содержать один или оба оригинальных подписанных установщика Rongta:

- `RongTaDriverInstall V2.65.exe`
- `DriverInstallArm64_V1.03.exe`

Бинарные файлы не хранятся в Git. Перед `tauri build` их необходимо положить в этот каталог либо передать путь через `CAFEHELP_PRINTER_DRIVER_DIR` для dev-проверки.
